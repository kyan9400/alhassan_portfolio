3:T4c5,Clearhire is an open-source recruiting platform I built with Claude Code to show a whole AI product, from reading a CV to deployment. A candidate can check a CV against a role before applying and see each requirement found or not, with the line of the CV that shows it; recruiters get the same reading, ranked.

The backend is Python: CVs in PDF, Word or scans go through Tesseract OCR into a profile with dated roles and evidence for each skill, pgvector embeddings power hybrid search, and a C++ skill matcher has a pure-Python fallback. Ranking uses the requirements, not one similarity number. Personal details are replaced before the embedding model reads the text, a local Qwen 3.5 9B writes summaries where uncited sentences are dropped, and every decision goes into a SHA-256 chained audit log whose Merkle roots are anchored hourly in a Solidity contract.

It is measured on a generated set of 312 CVs and 39 vacancies with known answers: nDCG@10 0.972 against 0.603 for embeddings alone, skills read with F1 0.997, and identical scores in all 486 blind-mode swaps of gender, origin and age. The demo runs live with Docker Compose on a GPU server, and a Helm chart is tested end to end on kind in GitHub Actions.4:T596,Depotwin is an open-source platform I built with Claude Code to show a real-time system end to end, measured against a ground truth. A Go simulator drives 240 vans, trucks and minibuses on the Moscow road network from OpenStreetMap, reports like GPS trackers do, and injects faults: fuel theft, failing thermostats and batteries, GPS spoofing, night use. What really happened is published apart, so detectors can be scored without seeing it.

Readings flow through NATS JetStream into TimescaleDB (13.4 million replayed with no gaps or repeats across restarts) and out to a 3D twin built with React, MapLibre and three.js. A FastAPI alerter finds faults as they happen, and LightGBM models on daily features warn of breakdowns: on unseen fleets they caught 156 of 157 overheating failures 4.5 days ahead, against 3.0 days for threshold rules, with fewer false alarms. A copilot on a local Qwen 3.5 9B can only call seven validated, read-only queries and shows the data behind each answer; it answered 17 of 18 held-out questions correctly.

Drivers use an Expo app that queues shifts, inspections and defect reports with photos offline and syncs them in order without duplicates; defects reach the twin at once. It indexes eight public documents — NIST and OWASP security guidance in English, the Russian personal data law in Russian, and two scans that only OCR can read.

Parsing follows each document's structure — PDF bookmarks and numbered headings, Word heading styles, one spreadsheet row per record — so results cite a page and section, an article of a law, or a sheet and row. Retrieval runs BM25 over Snowball-stemmed English and Russian words next to multilingual-e5 embeddings in FAISS, fuses the two rankings, and can rerank the top results with a multilingual cross-encoder.

Quality is measured on 62 hand-labelled questions: hybrid search puts a correct passage in the top five for 75.8% of them, and reranking raises that to 83.9%; the README also says where it is weak.
