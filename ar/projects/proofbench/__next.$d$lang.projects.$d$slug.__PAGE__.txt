3:T5a3,Proofbench is an open-source evaluation platform I built with Claude Code for an LLM agent that can do damage: a customer-support agent for a small shop that refunds money, cancels orders and reads other people's data. Almost every question worth asking about it has an exact answer, so it is decided from an effect log rather than by asking a model: what moved, by how much, on which order, whether something forbidden was attempted even if the shop refused it, and whether another customer appeared in the reply.

The agent is qwen3.5:9b running locally on one GPU. On the baseline it was fully correct on 75.0% of attempts and did nothing dangerous on 95.8%. The dominant failure is an agent that reasons correctly and then never calls the tool. Run with more randomness, the pass rate stayed exactly the same while the safety rate fell to 83.3%: it paid out on two of five planted instructions, which is why the two rates are kept apart.

Reply quality is the one thing a model judges, and the judge is measured: against five blind model raters it agreed at kappa 0.93 (95% CI 0.78–1.0). Recorded runs replay through the graders in 4 s instead of 18 minutes of GPU, and a CI gate fails if any grader's counts move, after a test showed the first version passing with a critical grader switched off. Every number on the live dashboard is re-graded by the current code, and the README keeps the measurements that turned out wrong, with why.4:T64f,Elektroservis keeps its engineering (PTO) documentation in a network archive of about 4.1k PDF, DOCX, XLSX and RTF files, about 1.5k of them with text. From April to October 2026, under civil-law contracts, I built a search service over it: an engineer types a cable mark, a document code, an equipment designation or a phrase and gets the document, the PDF page (or Excel sheet and rows, Word section), a text fragment and the network path. Documents never leave the company network.

Search is hybrid, with no LLM generation: a custom inverted index over words and designations, plus FAISS semantic search on sentence-transformers embeddings (all-MiniLM-L6-v2). Designations are matched by general rules: look-alike Latin and Cyrillic letters, spaces and hyphens do not break a match, while numbers and marks are never substituted. Scans are detected automatically and selected pages go through Tesseract + Poppler OCR. The backend is FastAPI, the interface is plain HTML/JS, and it runs as a systemd service on Ubuntu Server with an atomic index swap and rollback.

Code and mark queries went from 9–10 s to 1.2–1.7 s and phrase queries from 55–70 s to 2–4 s; after the move to the inverted index, p95 is 0.18 s on 55 control queries. Quality is held by 739 pytest tests and a 104-query control set with top-1/top-5 metrics. I built it with AI agents (Codex, Cursor, Claude Code): I gathered the requirements, wrote the agent briefs, reviewed the changes and checked them on the production index. The client accepted the work in September 2026. A double-entry ledger in Kotlin and Spring Boot keeps an append-only event log in PostgreSQL; balances are projections rebuilt from it, every write is idempotent, and an audit recomputes the books. Card payments, refunds and payouts run as state machines and sagas on top of it, and every change reaches Kafka through a transactional outbox.

It is proven by breaking it while a client keeps paying: services, PostgreSQL and Kafka killed, networks cut, answers cut off mid-way. Over 11 chaos scenarios and 40,461 requests (4,188 of them sent twice at once), a checker found nothing lost and nothing done twice. Load tests found the hot spots: the ledger does about 430 transfers a second on one CPU, shedding the excess instead of falling over.

A LightGBM model on real-time features from Kafka caught 88% of fraud at 0.7% false declines against 37% for tuned rules, measured against a simulator's hidden truth; ClickHouse analytics agree with the ledger to the kopeck. Merchants get a gRPC API, signed webhooks and a TypeScript SDK: with the service killed mid-payment, all 1,085 changes still reached the example shop.
